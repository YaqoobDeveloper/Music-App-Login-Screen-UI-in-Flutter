# Music App Login Screen UI in Flutter 🎧

A bold **lime login screen** built with Flutter, featuring a tiled headphone pattern, a big headphone logo, white rounded fields, a black **Login** button and Facebook, Twitter, Instagram and YouTube buttons, all in the friendly Quicksand font.

The UI is split into small, reusable components, the same way you would structure a React Native app.

## ✨ Features

- 🎧 Lime theme with a faint tiled headphone pattern
- 🤍 White rounded fields with leading icons and a divider
- 👁️ Eye button to show or hide the password
- ✅ Validation for email and password
- ⌨️ Press Enter on the password field to submit
- 📱 Facebook, Twitter, Instagram and YouTube login buttons
- 🧩 Reusable components with a barrel export (like `components/index.ts`)

## 📁 Project Structure

```
lib/
├── main.dart
```

## ▶️ Run

### 1. Clone the repository

```bash
git clone https://github.com/YaqoobDeveloper/Music-App-Login-Screen-UI-in-Flutter.git
```

### 2. Navigate to the project

```bash
cd Music-App-Login-Screen-UI-in-Flutter
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the app

```bash
flutter run
```
